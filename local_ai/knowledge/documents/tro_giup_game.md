# Hướng dẫn chơi game và phím tắt trên TrimUI

- Thoát game đang chơi: Bấm đồng thời START + SELECT (hoặc bấm nút MENU ở giữa thân máy) để thoát game và quay lại danh sách trò chơi.
- Mở Menu RetroArch: Trong khi đang chơi game giả lập, bấm nút MENU để mở cài đặt RetroArch.
- Lưu nhanh trạng thái game (Save State): Bấm giữ SELECT + R1.
- Tải lại trạng thái game đã lưu (Load State): Bấm giữ SELECT + L1.
- Tăng tốc độ game (Fast Forward): Bấm giữ SELECT + R2.
- Chụp ảnh màn hình trong game: Bấm giữ SELECT + X.
- Tăng giảm độ sáng màn hình: Giữ phím MENU kết hợp bấm nút L1 hoặc R1 để tăng giảm độ sáng.
- Tăng giảm âm lượng: Dùng phím gạt âm lượng bên cạnh hông máy hoặc giữ phím MENU kết hợp D-Pad lên xuống.
